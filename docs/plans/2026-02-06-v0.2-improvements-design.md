# ClipBook v0.2 — Improvements & Settings Design

**Date:** 2026-02-06
**Status:** Approved — ready for implementation

## Summary

v0.2 adds 5 features to the existing v0.1 code block processor:

1. **Keyless entries** — store values without naming them
2. **Auto-hide revealed values** — timer-based + blur-based re-masking
3. **Collapsible sections** — click section headers to collapse/expand
4. **Quick-add inline form** — add entries from the rendered view, writes back to source
5. **Settings tab** — 4 configurable options

## Architecture

### Data flow (v0.2)

```text
source → parseClipBook() → ClipBookData → renderClipBook(data, el, settings, ctx, app) → DOM
                                                                                  ↑
                                                                      quick-add writes back
                                                                      to source via Editor API
```

Key change from v0.1: `renderClipBook` now receives `settings`, `ctx` (MarkdownPostProcessorContext), and `app` to enable settings-aware rendering and editor write-back.

### File structure

```text
src/
  main.ts              # Plugin entry + settings load + registers processor
  types.ts             # + keyless entry support (key: string | null)
  parser.ts            # + bare-line and = value keyless parsing
  settings.ts          # NEW — ClipBookSettings interface, defaults, ClipBookSettingTab
  ui/
    renderer.ts        # + auto-hide, collapsible, settings-aware rendering
    copy.ts            # unchanged
    quick-add.ts       # NEW — inline form, editor write-back
  utils/
    mask.ts            # unchanged
```

## Feature 1: Keyless Entries

### Syntax

Two ways to write a keyless entry:

```ini
# Bare line (no = sign):
!sk-proj-abc123def456        # keyless, masked
us-east-1                    # keyless, plain

# Empty-key with = sign:
= !sk-proj-abc123def456      # keyless, masked
= us-east-1                  # keyless, plain
```

### Parsing rules (priority order)

1. Empty line or comment (`#`, `;`) → skip
2. Section header `[Name]` → new section
3. Contains `=` → split on first `=`. If key is empty string after trimming, treat as keyless entry.
4. **New:** No `=` → entire line is a keyless entry. If starts with `!`, value is masked.

### Type change

```typescript
// types.ts
export interface ClipBookEntry {
  key: string | null;  // null = keyless entry (was: string)
  value: string;
  masked: boolean;
}
```

### Rendering

When `entry.key` is `null`:
- The key label span is omitted entirely
- The value span takes full width (`flex: 1`)
- Copy button `aria-label` uses `"Copy value"` instead of `"Copy ${key}"`

## Feature 2: Auto-Hide Revealed Values

### Timer-based auto-hide

When a user clicks a masked value to reveal it, a timer starts. After `autoHideTimeout` seconds, the value re-masks automatically.

```typescript
// Inside renderEntry toggleReveal closure
let hideTimer: ReturnType<typeof setTimeout> | null = null;

const toggleReveal = () => {
  revealed = !revealed;
  valueEl.setText(revealed ? value : maskValue(value));
  valueEl.toggleClass("clipbook-revealed", revealed);
  valueEl.setAttribute("aria-label",
    revealed ? "Click to hide value" : "Click to reveal value");

  if (hideTimer) clearTimeout(hideTimer);
  if (revealed && settings.autoHideTimeout > 0) {
    hideTimer = setTimeout(() => {
      revealed = false;
      valueEl.setText(maskValue(value));
      valueEl.toggleClass("clipbook-revealed", false);
      valueEl.setAttribute("aria-label", "Click to reveal value");
    }, settings.autoHideTimeout * 1000);
  }
};
```

### Blur-based auto-hide

When the user switches tabs or the window loses focus, all currently revealed values re-mask instantly. This is independent of the timer.

Implementation: In `main.ts`, register workspace events that trigger a global re-hide:
- `this.registerEvent(this.app.workspace.on("active-leaf-change", hideAllRevealed))`
- `this.registerDomEvent(window, "blur", hideAllRevealed)`

The `hideAllRevealed` function queries all `.clipbook-revealed` elements and triggers their hide behavior. To make this work, each revealed value registers itself in a module-level `Set<() => void>` of hide callbacks, and removes itself when hidden.

### Edge cases

- `autoHideTimeout = 0` ("Never") → no timer, same as v0.1 behavior
- User manually hides before timer fires → timer is cleared
- User copies then timer fires → value was already copied, re-masking is cosmetic
- Block re-render (e.g., switching notes) → always resets to masked (Obsidian behavior)

### Settings

- `autoHideTimeout: number` — seconds. Dropdown: 3, 5, 10, 30, 0 (Never). Default: 5.
- `hideOnTabSwitch: boolean` — Toggle. Default: true.

## Feature 3: Collapsible Sections

### Behavior

Each named section header becomes clickable. A chevron icon indicates collapsed/expanded state.

### Implementation

```typescript
// Inside renderSection
if (section.name !== null) {
  const headerEl = sectionEl.createDiv({ cls: "clipbook-section-header" });
  const chevronEl = headerEl.createSpan({ cls: "clipbook-chevron" });
  headerEl.createSpan({ text: section.name });

  let collapsed = settings.defaultCollapsed;
  setIcon(chevronEl, collapsed ? "chevron-right" : "chevron-down");

  const entriesEl = sectionEl.createDiv({ cls: "clipbook-entries" });
  if (collapsed) entriesEl.style.display = "none";

  headerEl.addEventListener("click", () => {
    collapsed = !collapsed;
    setIcon(chevronEl, collapsed ? "chevron-right" : "chevron-down");
    entriesEl.style.display = collapsed ? "none" : "";
  });

  for (const entry of section.entries) {
    renderEntry(entry.key, entry.value, entry.masked, entriesEl, settings);
  }
}
```

### Decisions

- **Orphan entries** (section.name === null) are never collapsible — no header to click.
- **Collapse state is ephemeral** — resets on block re-render. No persistence for v0.2.
- **No animation** — simple `display: none` toggle. Snappy and simple.
- **Chevron icons** — Obsidian built-in `chevron-right` / `chevron-down` via `setIcon`.

### CSS additions

```css
.clipbook-section-header {
  cursor: pointer;
  user-select: none;
}
.clipbook-chevron {
  display: inline-flex;
  align-items: center;
  margin-right: 4px;
}
.clipbook-chevron svg {
  width: 12px;
  height: 12px;
}
```

### Setting

- `defaultCollapsed: boolean` — Default: false (sections start expanded).

## Feature 4: Quick-Add Inline Form

### UI

A `[+ Add]` button at the bottom of each rendered clipbook block. Clicking it reveals an inline form:

```text
┌─────────────────────────────────────────────────┐
│  Section:  [ existing-section ▼ / new name ]    │
│  Key:      [ optional label________________]    │
│  Value:    [ paste or type value here______]    │
│  ☑ Mask this value                              │
│                          [ Cancel ] [ Add ]     │
└─────────────────────────────────────────────────┘
```

**Fields:**

1. **Section** — Combo input (dropdown of existing section names + free text for new). Blank = orphan entry at top.
2. **Key** — Optional text input. Blank = keyless entry.
3. **Value** — Required text input. Add button disabled when empty.
4. **Mask toggle** — Checkbox. Default: per `quickAddDefaultMask` setting.

### Write-back mechanism

1. User fills form and clicks "Add"
2. Call `ctx.getSectionInfo(el)` to get the code block's line range in the source
3. Access the editor: `app.workspace.getActiveViewOfType(MarkdownView)?.editor`
4. Build the new line(s):
   - Masked keyless: `!value`
   - Plain keyless: `value` (but needs `=` prefix to avoid ambiguity with bare text) → `= value`
   - Masked with key: `Key = !value`
   - Plain with key: `Key = value`
5. Determine insertion point:
   - **Existing section:** Find the section's last entry line within the code block, insert after it
   - **New section:** Insert `\n[SectionName]\n` + entry line before the closing fence
   - **Orphan (no section):** Insert at the top of the code block (after the opening fence)
6. Use `editor.replaceRange()` to insert the line(s)
7. Obsidian automatically re-renders the block after source changes

### New file: `src/ui/quick-add.ts`

Exports:
- `renderQuickAddButton(containerEl, data, settings, ctx, app)` — renders the [+ Add] button
- Internal: `renderQuickAddForm(...)` — renders the form, handles submit

### Edge cases

- `ctx.getSectionInfo(el)` returns null → Add button not rendered (graceful degradation). This can happen in embedded/exported contexts.
- Empty value field → Add button stays disabled
- Form closes after successful add (block re-renders automatically)
- If editor is not available (e.g., canvas embed) → Add button not rendered

### CSS

## Feature 5: Settings Tab

### Interface

```typescript
// settings.ts
export interface ClipBookSettings {
  autoHideTimeout: number;      // seconds, 0 = never. Default: 5
  hideOnTabSwitch: boolean;     // re-mask on blur/tab switch. Default: true
  defaultCollapsed: boolean;    // sections start collapsed. Default: false
  quickAddDefaultMask: boolean; // mask checkbox default in quick-add. Default: true
}

export const DEFAULT_SETTINGS: ClipBookSettings = {
  autoHideTimeout: 5,
  hideOnTabSwitch: true,
  defaultCollapsed: false,
  quickAddDefaultMask: true,
};
```

### Settings tab

```typescript
export class ClipBookSettingTab extends PluginSettingTab {
  plugin: ClipBookPlugin;

  constructor(app: App, plugin: ClipBookPlugin) {
    super(app, plugin);
    this.plugin = plugin;
  }

  display(): void {
    const { containerEl } = this;
    containerEl.empty();

    // Auto-hide timeout dropdown
    new Setting(containerEl)
      .setName("Auto-hide revealed values")
      .setDesc("Re-mask revealed values after this duration")
      .addDropdown(dropdown => dropdown
        .addOption("3", "3 seconds")
        .addOption("5", "5 seconds")
        .addOption("10", "10 seconds")
        .addOption("30", "30 seconds")
        .addOption("0", "Never")
        .setValue(String(this.plugin.settings.autoHideTimeout))
        .onChange(async value => {
          this.plugin.settings.autoHideTimeout = Number(value);
          await this.plugin.saveSettings();
        })
      );

    // Hide on tab switch toggle
    new Setting(containerEl)
      .setName("Hide on tab switch")
      .setDesc("Re-mask all revealed values when switching to another tab or window")
      .addToggle(toggle => toggle
        .setValue(this.plugin.settings.hideOnTabSwitch)
        .onChange(async value => {
          this.plugin.settings.hideOnTabSwitch = value;
          await this.plugin.saveSettings();
        })
      );

    // Default collapsed toggle
    new Setting(containerEl)
      .setName("Sections start collapsed")
      .setDesc("Whether sections are collapsed by default in reading view")
      .addToggle(toggle => toggle
        .setValue(this.plugin.settings.defaultCollapsed)
        .onChange(async value => {
          this.plugin.settings.defaultCollapsed = value;
          await this.plugin.saveSettings();
        })
      );

    // Quick-add default mask toggle
    new Setting(containerEl)
      .setName("Mask new entries by default")
      .setDesc("Whether the mask checkbox is checked by default in the quick-add form")
      .addToggle(toggle => toggle
        .setValue(this.plugin.settings.quickAddDefaultMask)
        .onChange(async value => {
          this.plugin.settings.quickAddDefaultMask = value;
          await this.plugin.saveSettings();
        })
      );
  }
}
```

### Plugin lifecycle (main.ts)

```typescript
import { Plugin, MarkdownView } from "obsidian";
import { parseClipBook } from "./parser";
import { renderClipBook } from "./ui/renderer";
import { ClipBookSettings, DEFAULT_SETTINGS, ClipBookSettingTab } from "./settings";

export default class ClipBookPlugin extends Plugin {
  settings: ClipBookSettings;

  async onload() {
    await this.loadSettings();
    this.addSettingTab(new ClipBookSettingTab(this.app, this));

    this.registerMarkdownCodeBlockProcessor("clipbook", (source, el, ctx) => {
      const data = parseClipBook(source);
      renderClipBook(data, el, this.settings, ctx, this.app);
    });

    // Blur-based auto-hide
    if (this.settings.hideOnTabSwitch) {
      this.registerEvent(
        this.app.workspace.on("active-leaf-change", () => hideAllRevealed())
      );
      this.registerDomEvent(window, "blur", () => hideAllRevealed());
    }
  }

  async loadSettings() {
    this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData());
  }

  async saveSettings() {
    await this.saveData(this.settings);
  }
}
```

Note: The blur event registration uses `this.register*` helpers for proper cleanup on unload.

## Out of scope for v0.2

- Inline key-value rendering (Phase 2 — separate design)
- Editing existing entries through the rendered UI
- Search/filter within the rendered view
- Import/export
- Encryption of values at rest
- "Copy all" or "copy section" buttons
- Persistent collapse state across re-renders
- CSS animations for collapse/expand
